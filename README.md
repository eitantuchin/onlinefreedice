# Online Free Dice

A simple React website for rolling a die online with animation, visual interaction, and probability insights.

Website: https://onlinefreedice.com/

## Features

- Click the visual die or the button to roll
- Smooth die roll animation for a modern UI
- Responsive layout for desktop and mobile
- Dice probability explanation with odds and chance details
- SEO-friendly title, description, and keywords for online dice roll search

## Stack

- React
- Vite
- JavaScript
- CSS

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local URL shown in your terminal.

## Build

```bash
npm run build
```

## Notes

This website is a free online dice roller built to support tabletop gaming, dice probability practice, role-playing games, and quick random decision making.
